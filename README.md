# ShoppingCart — Qualtrics Online Grocery Survey Instrument

An online grocery shopping cart survey built in Qualtrics for nutrition research. Participants browse 240 items across 10 product categories, select what they want in their cart, and are pre-assigned a basket condition that pre-selects certain items to nudge their choices. The survey records final selections, calculates a health score, and writes all data to Qualtrics embedded data fields for analysis.

## How It Works

1. A participant lands on a single Qualtrics page containing all 10 product categories.
2. JavaScript assigns them one of four **basket conditions** (healthy_a, healthy_b, unhealthy_a, unhealthy_b), pre-checking 2 items per category to simulate a default shopping cart.
3. The participant freely adds and removes items. A live **Your Cart** sidebar shows their running total, health breakdown, and item list. Selection is capped at **30 items**.
4. On submission, health score and per-category selections are written as Qualtrics embedded data.

```

       └─ Sets basket condition via radio button (or random assignment)
       └─ Hosts window.ITEM_REGISTRY and all preselection logic (global JS scope)

Q17 — Snacks  │  • Builds the shared two-column layout on first load
Q18 — Fruit   │  • Moves itself into the shared main panel
Q19 — Meat/   │  • Registers a scroll-sticky cart sidebar
       Seafood │  • Enforces the 30-item cap across all categories
Q20 — Frozen  │  • Updates the sidebar and embedded data on every change
Q21 — Pantry  │
```

The **ITEM_REGISTRY** is a JavaScript object keyed by exact item label text. Each entry records the item's category, health tag (healthy/unhealthy), and basket preselection flags for all four conditions.

## Building the Registry

`build_registry.py` reads the master Excel file and rewrites the auto-generated section of `condition question and item metada registry.js`.

**Basic run (uses Excel as sole source):**
```
python build_registry.py
```

**With label overrides (for items where fuzzy matching fails):**
```
python build_registry.py --overrides my_overrides.xlsx
```

The overrides file must contain a sheet named `label_overrides` with two columns:

| ItemID | QualtricsLabel |
|--------|----------------|
| DRK1   | Natural spring water |
| MEA2   | Steak |
| FRZ12  | Chocolate icecream |

**What the script does:**

1. Reads the `qualtrics` tab for authoritative Qualtrics-rendered label text
2. For each of the 8 non-Bakery/Dairy categories, resolves item labels via:
   - Tier 1: exact match on Final Label or Product Name (case-insensitive)
   - Tier 2: fuzzy match (SequenceMatcher ≥ 85% similarity)
   - Tier 3: label overrides from `--overrides` file
3. Reads the `baskets` tab for all 10 categories' basket assignments
4. Regenerates the ITEM_REGISTRY block and patches it into the JS file
5. Prints next-step deployment instructions

**Output:** The script updates `condition question and item metada registry.js` in place. It does not touch any other file.

## Deploying to Qualtrics

After running `build_registry.py`, deploy the three JS files to Qualtrics:

### Q1 — Condition Picker

1. Open Q1 in the Qualtrics survey editor
2. Click **JavaScript**
3. Paste the entire contents of `condition question and item metada registry.js` **above** the `addOnReady({ ... })` block (in the global scope area)
4. Save

### Q14 — Bakery

1. Open Q14 in the editor
2. Click **JavaScript**
3. Replace all content with `Q14 Bakery Question and loader.js`
4. Save

### Q15–Q23 — All other categories

1. Open each question in turn
2. Click **JavaScript**
3. Replace all content with `Other categories 9 to 10 question.js`
4. Save

**Testing after deployment:**

1. Preview the survey
2. Open the browser developer console
3. Select a basket condition — the console should print:
   ```
   applied N pre-selections for condition healthy_a
   ```
   once per category (10 lines total)
4. Verify the correct items are pre-checked in the cart
5. Test all four conditions: `healthy_a`, `healthy_b`, `unhealthy_a`, `unhealthy_b`

## Updating the Survey

### When item labels change in Qualtrics

1. Open the survey in Qualtrics **Preview** mode
2. Open the browser developer console
3. Paste and run `export qualtrics labels via console.js`
4. Copy the JSON output into the **`qualtrics`** tab of `Combined Justification 8.05.2026.xlsx`
5. Run `python build_registry.py`
6. Paste the updated JS into Q1 ([see Deploying](#deploying-to-qualtrics))

### When new items are added

1. Add a row to the relevant category tab in the Excel file (ItemID, Product Name, Tag, Final Label)
2. Add a basket assignment row to the `baskets` tab
3. Re-export Qualtrics labels (step 1–4 above)
4. Run `python build_registry.py`
5. If the script warns `no confident match for <ItemID>`, add the item to an overrides file and re-run with `--overrides`

### When basket assignments change

1. Edit the **`Y` markers** in the `baskets` tab of the Excel file
   - `Y` = pre-selected for that condition; blank = not selected
   - Required columns: `ItemID | Category | Label | Tag | HealthyA | HealthyB | UnhealthyA | UnhealthyB`
2. Run `python build_registry.py`
3. Deploy updated JS to Q1

## Basket Conditions

Each participant is assigned one of four conditions. Each condition pre-selects 2 items per category:

| Condition | Pre-selected items |
|-----------|-------------------|
| `healthy_a` | 2 healthy items (set A) per category |
| `healthy_b` | 2 healthy items (set B) per category |
| `unhealthy_a` | 2 unhealthy items (set A) per category |
| `unhealthy_b` | 2 unhealthy items (set B) per category |

**Bakery and Dairy** — assignments specified by the researcher in the original `baskets.csv` / baskets tab.

**All other 8 categories** — assignments stored in the `baskets` tab and must be completed by the researcher before production use. The script warns for any ItemID missing from the baskets tab.

## Embedded Data Output

The JavaScript writes the following embedded data fields to Qualtrics on submission:

| Field | Value |
|-------|-------|
| `condition` | Basket condition key (e.g., `healthy_a`) |
| `total_items` | Total items selected across all categories |
| `healthy_items` | Count of items tagged `healthy` |
| `health_score` | Percentage of selected items that are healthy (0–100) |
| `{category}_count` | Items selected in that category (e.g., `bakery_count`) |
| `{category}_labels` | Comma-separated labels for that category (e.g., `bakery_labels`) |

Category keys: `bakery`, `dairy_eggs_fridge`, `drinks`, `snacks`, `fruit`, `meat_seafood`, `frozen`, `pantry`, `ready_to_eat`, `vegetables`
